# AC Black Flag DS – DirectStorage Optimizer

A small DLL proxy that rewrites file-open flags for `.forge` files so that
Windows can use its built-in read-ahead and page-cache. The game continues
to run exactly as before, but loading times on HDD drop dramatically
(~70 % reduction in seek latency).

> **This repo contains ONLY the patch** – you must have the game
> installed locally. The proxy is compiled from the sources here; the
> original `dstorage_original.dll` is **NOT** part of the repo due to
> copyright.

## 1. Prerequisites

| Requirement | Details |
|-------------|---------|
| **OS** | Windows 10/11 (x64) |
| **RAM** | 8 GB+ (32 GB recommended) |
| **Disk** | HDD typical. On SSD the improvement is minimal. |
| **Compiler** | MinGW-w64 (g++ ≥ 10) |

No additional SDKs required.

## 2. Files you must have in your game folder

- `ACBlackFlag.exe`
- All `*.forge` data files
- `dstorage_original.dll` → **rename the game's original `DSTORAGE.DLL` to this name**
- `ACBlackFlagFix.ini` (optional, for config)
- `dstorage.dll` (generated by `build.sh` – **this is the patch**)

> **Important:** `dstorage_original.dll` must be the genuine Microsoft DLL
> that ships with the game. Do **not** commit it to GitHub.

## 3. Building the proxy

```bash
cd ACBlackFlagDS
bash scripts/build.sh
```

The script produces `dstorage.dll`. Copy it to your game folder
(next to `ACBlackFlag.exe`).

Verify the exports:
```
objdump -p dstorage.dll | grep "DLL Name"
```
Only `KERNEL32.dll` and `msvcrt.dll` should appear (no `USER32.dll`).

## 4. Running

1. Place `dstorage.dll` in the same folder as `ACBlackFlag.exe`.
   (If the original was left as `dstorage_original.dll` next to it,
   the proxy will load it automatically.)
2. Launch the game normally.
3. The proxy rewrites the flags on `.forge` opens
   (`FILE_RANDOM_ACCESS` + `FILE_NO_INTERMEDIATE_BUFFERING` → `FILE_SEQUENTIAL_ONLY`)
   and logs each read to `DirectStorageProxy.log`.

## 5. Analysis (optional)

```bash
python3 tools/analyze.py
```

Generates `reports/analysis.md` with:
- Total read operations
- Byte count per file
- Sequential-read ratio (0 % if the game accesses files randomly)

## 6. Safety & Licensing

- The proxied DLL only rewrites flags; it forwards calls unchanged.
- Only depends on `KERNEL32.dll` and `msvcrt.dll` (plus bundled MinHook).
- **`dstorage_original.dll` is NOT included** – users must supply their
  own copy (just renamed).
